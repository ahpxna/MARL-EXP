## 1. Statement

Let `Theta` be a finite nonempty set of worlds, `R : Theta -> R^d` a response map,
`g : Theta -> Q` a scalar target, `sigma_1..sigma_d > 0` declared per-coordinate
measurement accuracies, and `||x||_{w,inf} = max_i |x_i| / sigma_i`. Observations are
`y = R(theta) + e` with `||e||_{w,inf} <= eta`, `eta >= 0`.

**(T1)**
```
E*_eta  :=  inf_psi  sup_{theta in Theta}  sup_{||e||_{w,inf} <= eta} |psi(R(theta)+e) - g(theta)|
        =  (1/2) * max { |g(a) - g(b)| : a,b in Theta, ||R(a)-R(b)||_{w,inf} <= 2 eta }
```

**(T2)** With `Bad(eps) := { {a,b} : |g(a)-g(b)| > 2 eps }`:
* if `Bad(eps)` is empty, the tolerance `eps` is met at **every** `eta`, including
  `eta = +inf`; there is no critical radius and none is reported;
* otherwise `eta_crit(eps) := (1/2) * min { ||R(a)-R(b)||_{w,inf} : {a,b} in Bad(eps) }`
  and `E*_eta <= eps` for every `eta < eta_crit(eps)`, while `E*_{eta_crit(eps)} > eps`.
  The set of certifying radii is exactly the half-open interval `[0, eta_crit(eps))`.

`E*_0` coincides with the exact-key radius already used in this repo (max half-diameter
over fibres of the exact key).

## 2. Assumptions

1. `Theta` finite and nonempty; `g` real (rational in every computation here).
2. The noise set is the closed `||.||_{w,inf}` ball of radius `eta` — closed, symmetric,
   convex. The `<=` in `||R(a)-R(b)|| <= 2 eta` is load-bearing: with `<` the value at
   the boundary changes (certified by a control in the probe).
3. Observations compatible with no world are outside the supremum, so the decoder's
   value there is unconstrained.
4. The decoder is an arbitrary function of `y` alone — no measurability, no
   restriction to a hypothesis class, no prior.
5. **Empirical part only:** the RWARE panel artifact
   `research/high_risk_20260910/QUERY_natural_panel_v2.json`
   (`script_sha256 = eb552b84f8701cc1d396712b1f70901b17b5ad8e1ade785a2d4f0e8be3ea9e37`)

## 3. Nearest prior work

* **Classical.** This is the optimal-recovery / modulus-of-continuity framework
  (Donoho, *Statistical Estimation and Optimal Recovery*): `E*_eta` is
  `omega(2 eta)/2` for the modulus `omega(delta) = sup{|g(a)-g(b)| : ||R(a)-R(b)|| <= delta}`,
  and the midpoint-of-the-compatible-set rule is the classical optimal recovery
  estimator. **The identity (T1) is not novel and is not claimed as novel.**

* The `eta > 0` case is **not** formalised anywhere in `work/p13_conjectures/`

## 4. Proof

**Lower bound.** Fix `a,b` with `||R(a)-R(b)||_{w,inf} <= 2 eta` and set
`y = (R(a)+R(b))/2`. Then `y - R(a) = (R(b)-R(a))/2` has `||.||_{w,inf} <= eta`, and
likewise for `b`, so `y` is an admissible observation under both worlds. For any `psi`,
`|g(a)-g(b)| <= |psi(y)-g(a)| + |psi(y)-g(b)| <= 2 max(...)`, so the supremum is at least
`|g(a)-g(b)|/2`. Take the max over such pairs.

**Upper bound.** Let `C(y) = { theta : ||y-R(theta)||_{w,inf} <= eta }` and define
`psi(y) = (max_{C(y)} g + min_{C(y)} g)/2` when `C(y)` is nonempty (anything otherwise).
For any `theta` and admissible `e`, `theta in C(R(theta)+e)`, and any two members of
`C(y)` are within `2 eta` of each other by the triangle inequality, so the `g`-range over
`C(y)` is at most `2 * RHS`. Hence `|psi(y)-g(theta)| <= RHS`. ∎

The proof uses only the triangle inequality and symmetry of the ball, so (T1) holds for
any norm; **only the weighted inf-norm was checked numerically.**

**(T2).** If `eta < eta_crit(eps)` then `2 eta < min_{Bad(eps)} ||R(a)-R(b)||`, so every
pair compatible at `eta` has `|g(a)-g(b)| <= 2 eps` and `E*_eta <= eps` by (T1). At
`eta = eta_crit(eps)` the minimising pair is compatible and has `|g(a)-g(b)| > 2 eps`,
so `E*_eta > eps`. ∎

**Non-triviality (this is *not* a relabelling of the exact-key quotient).** The relation
"`||R(a)-R(b)|| <= 2 eta`" is **not transitive**. On the designed panel
`R = (0, 2, 4)`, `g = (0, 5, 10)`, `eta = 1`, the pairwise value is `5/2` while treating
the relation as an equivalence and taking connected components gives `5`. The probe
**asserts** that these differ; if they ever agreed, the control would not be a control.

## 6. Answer to the decisive question, stated plainly

> *Do instances whose exact keys are all distinct nevertheless have `eta_crit` near zero?*

The answer is **mixed, and the honest version is narrower than "yes":**

1. **Universally true on this panel:** no exact-key-sufficient representation survives
   `eta = 1/2`, i.e. one quantum of measurement blur (one delivery, one grid cell, or one
   full feature range). Every one of the eleven `eta_crit(0)` values above is below
   `0.089`. This is asserted by the probe (`headline 1`).
2. **Universally true on this panel:** in *every* exact-key-sufficient representation the
   critical (minimum-distance bad) pair is separated **only** by float model-output
   coordinates — `relation_features` and/or `weak_prior_score`. **No** critical pair is
   separated by a query response (`c1` or `c2`), and **no** critical pair is separated by
   `privileged_geometry`, even though every sufficient subset contains it. The tightest
   part of the certificate therefore rests entirely on learned float features for which
   this repo documents no units and no noise scale. Asserted (`headline 2`).
3. **Not uniformly "near zero".** For the `relation_features`-based repairs the critical
   separation is `2/9` of a raw `relation_features[0]` unit — that feature takes only 18
   distinct values on a `1/9` grid, so the critical pair is exactly two grid steps apart.
   That is a real margin, not a floating-point accident. Calling it "near zero" would be
   overclaiming. For the `weak_prior_score`-based repairs the critical separation is
   `0.0062` on a feature of range `0.503` (1.2%), and `eta_crit` there sits exactly on the
   packing floor — that one **is** as fragile as the packing permits.
4. **The 1-step query response by itself certifies nothing at any resolution.** On the
   full panel `E*_eta = 3/5` — the no-information value — for `c1` at every `eta`
   including `eta = 0`; and `1580/1600` units have an identically zero `c1`.

**Consequence for the existing claim.** "Two catalog items suffice" must be restated as:
*on the 59-unit non-constant-target subpanel, and with exact float64 bit equality as the
key, two items make the exact keys sufficient; the certificate is destroyed by a
measurement resolution of 0.06–0.09 accuracy units, it rests entirely on undocumented
float model outputs, and on the full 1600-unit panel it is false.* That is a fragile
claim, and it should be published with its scope and its `eta_crit` attached or not
published as sufficiency at all.

## 7. What this does NOT establish

* It does **not** establish any novelty for (T1) or (T2). Both are the finite-`Theta`
  specialisation of Donoho's optimal-recovery modulus of continuity. The contribution
  here is the audit and the numbers, not the identity.
* It does **not** establish (T1)/(T2) in Lean. No `.lean` file was written or compiled,
  and the existing `eta = 0` Lean modules have **no compile receipts**, so even the
  `eta = 0` case is not PROVED-certified under this project's rule. Evidence class for
  the identity: hand proof (Section 4) plus exact numerical certification over 37 cells —
  not a machine-checked proof.
* It does **not** establish (T1) for norms other than the weighted inf-norm. The proof in
  Section 4 uses only the triangle inequality and symmetry, so it should extend, but
  nothing outside the weighted inf-norm was computed.
* It does **not** establish anything about `eta` in *physical* units for the float
  features. `sigma` for those is a declared normalisation (observed dynamic range), not a
  measured instrument accuracy. Every float-feature conclusion is conditional on that
  declaration; raw separations are reported so a real spec can override it.
* It does **not** validate the panel. The panel was consumed, not regenerated; its
  collection policy, its 20 seeds, its horizon 6 and its greedy continuation policy `rho`
  are taken as given. With 1541/1600 constant targets and 1580/1600 zero 1-step
  responses, this panel is nearly degenerate, and *no* conclusion here transfers to a
  panel where the query response actually moves.
* It does **not** establish that `privileged_geometry` is or is not a world index. It is a
  privileged state read (`x`, `y`, `dir`, carrying flags, two Manhattan distances) with a
  real physical quantum, and it was kept in the norm with `sigma = 1` — the treatment most
  favourable to the claim, since adding coordinates can only increase distances. `dir` is
  a categorical code and was nonetheless given the metric `sigma = 1`; treating it as an
  exact categorical key (distance `+inf` when different) would be exactly the
  "world index in `R`" pattern and would make `eta_crit` vacuously infinite for pairs
  separated by `dir`. No critical pair is separated by `privileged_geometry` at all, so
  this choice does not affect any headline.
* It does **not** establish a generalisation bound. `eta_crit` is computed on the
  collected units; nothing here says a new unit would not land arbitrarily close to an
  existing one and drive `eta_crit` to zero. The prior work's own holdout abstain rate for
  the sufficient subsets is 0.867–0.933, which points the same way.
* It does **not** claim the prior work's confound controls are wrong. They are sound in
  principle and vacuous on this artifact.
* The 32-subset sweep on the **full** panel was **not** run: 1600 units is 1,279,200 pairs
  per subset, so the full panel was run for 6 declared representations and the 32-subset
  sweep for the 59-unit subpanel. The full-panel distances are float64 with only the
  arg-min pair re-certified in exact rational arithmetic. Both restrictions are stated in
  the probe's docstring and printed at run time; nothing was silently truncated.

## 8. Decision

**FIX.**

* Keep `scripts/N5_resolution_minimax.py` as the resolution-robustness harness — it is
  cheap (14 s), it fails loudly, and its controls discriminate.
* Restate, do not delete, the QUERY sufficiency result: it must carry (a) the subpanel
  scope, (b) `eta_crit`, and (c) the fact that the tightest certificate is carried by
  float model outputs with no documented accuracy.
* Drop any framing of (T1)/(T2) as a new theorem. If it is written up at all, it is a
  named instance of Donoho optimal recovery used as a validation instrument.
* The prior artifact should record that `catalog_purchases`/`repair` are subpanel-only and
  that its two "can_fail" controls are vacuous on this panel.
