## 1. Statement

Fix integers `m, s, L` with `s >= 1`, `L >= 1`, `m > s*L`.
Primitive UNCHANGED from `scripts/SUPPORT_depth_probe.py`:

* hidden world `W subset Z_m`, `|W| = s`;
* window `A_j = {j, j+1, ..., j+L-1} mod m`;
* query = point membership, one bit: `oracle(a) = (a in W)`;
* decision `j` is SAFE iff `A_j cap W = empty`;
* a transcript `(q0 = NO set, q1 = YES set)` admits a certified decision iff
  some `j` has `A_j cap q1 = empty` and (`A_j subset q0` or `|q1| = s`)
  -- verbatim the `terminal` predicate of `SUPPORT_depth_probe.Game`.

**N3-1 (main).** The NONADAPTIVE (one-batch) zero-error worst-case query
complexity is exactly

        D_nonadaptive(m, s, L) = s * L.

**N3-2 (measured adaptivity gain).** With `H(m,s,L)` the fully adaptive minimax
depth, the adaptivity gain `s*L / H` **never exceeded 1.778** on the exact grid
computed here (maximum at `m=17, s=2, L=8`: `16 / 9`; the maximum in the
default, no-`--long` run is `1.75` at `m=15, s=2, L=7`: `14 / 8`). Conditional on the
repo's parity law `H = floor(s/2)(L+1) + (s mod 2) L` -- which this probe
re-verified on every cell it computed, including even `L`, which the prior
sweep never exercised -- the gain in closed form is

        s even:  s*L/H = 2L/(L+1)                 < 2
        s odd:   s*L/H = 2sL/(sL + s + L - 1)     < 2

with supremum exactly 2, **never attained**. This cyclic family therefore
CANNOT support an unbounded adaptivity separation.

## 2. Assumptions

1. `m > s*L`, `s >= 1`, `L >= 1`. **Load bearing, verified (part F):** at
   `m = s*L` the equispaced world `{0, L, 2L, ...}` hits every window, no safe
   action exists in any world-consistent sense, and the exact minimax returns
   `INF` for `(s,L) in {(2,1),(3,1),(4,1),(2,2),(3,2),(2,3),(2,4)}`.
2. Exact cardinality promise `|W| = s`. (The upper bound also survives the
   weaker `|W| <= s` promise; the lower bound is stated for `|W| = s`.)
3. Zero error: the output must be safe in EVERY world consistent with the
   transcript. No noise, no probability, no regret slack.
4. Deterministic protocols only. Randomised / distributional lower bounds are
   NOT addressed.
5. For N3-2's closed form only: the parity law for `H`. `H` itself was computed
   exactly (not assumed) on every row above.

## 4. Proof (N3-1) and negative control

### 4.1 Upper bound `D_nonadaptive <= s*L`

Since `m > s*L`, the `s` blocks `B_i = {iL, ..., iL+L-1}`, `i = 0..s-1`, are
pairwise disjoint. Query `Q = union B_i`, `|Q| = s*L`, one shot. Decide:

* if some `B_i` is all-NO, output `j = iL`; then `A_j = B_i` and
  `A_j cap W = empty`, so it is safe;
* otherwise every `B_i` contains a YES. **The disputed step, checked:** the
  blocks are pairwise disjoint, so those YES points are `>= s` DISTINCT
  elements of `W`; as `|W| = s` there are exactly `s` of them and the observed
  YES set IS `W`. Now every point of `W` lies in exactly `L` windows, so at
  most `s*L` of the `m` windows are killed, and `m > s*L` leaves one alive.

Part A runs exactly this protocol against **every** world of size `s` on 15
configurations and asserts each of the three claims (disjointness, "exactly
`s` holes observed", "a safe window survives") separately. 165 worlds at the
largest cell; both branches are exercised in every row (columns
`all-NO used` / `holes used` are both nonzero).

### 4.2 Lower bound `D_nonadaptive >= s*L`

Let `Q` be any query set with `|Q| < s*L`.

1. `|Q| < s*L < m`, so some `p notin Q`. Cut the cycle at `p`. Every window
   contained in `Q` avoids `p`, hence is a contiguous interval of the induced
   line order. (Asserted pointwise in `greedy_hitting_set`.)
2. Greedy by smallest right endpoint on the family `F` of windows inside `Q`:
   take the interval with least right endpoint, place a hit there, delete every
   interval containing that point, repeat. The `k` intervals picked are
   pairwise disjoint: the next pick has strictly larger right endpoint and does
   not contain the previous hit point, hence its left endpoint is strictly to
   the right of it. They are disjoint, of size `L`, and inside `Q`, so
   `k*L <= |Q| < s*L`, giving `k <= s-1`. Call the hit set `Y subset Q`,
   `|Y| = k`.
3. Answer YES on `Y`, NO on `Q \ Y`.
4. **Consistency (mandatory).** `Y union Q^c` hits EVERY one of the `m` cyclic
   windows: a window inside `Q` is hit by `Y` by construction, and a window not
   inside `Q` contains a point of `Q^c`. Each point lies in exactly `L` windows,
   so any hitting set has size `>= ceil(m/L)`, and `m >= s*L + 1` gives
   `ceil(m/L) >= s+1`. Hence
        `|Y| + |Q^c| >= s + 1`.
   With `|Y| <= s-1` this yields `|Q^c| >= s + 1 - |Y| > s - |Y| >= 1`, so a
   world `W` of size `s` with `Y subset W` and `W cap (Q\Y) = empty` exists:
   the transcript is NOT impossible.
5. For any output `j`: if `A_j cap Y != empty` then `j` is unsafe in every
   consistent world. Otherwise `A_j` is not inside `Q` (else `Y` would hit it),
   so it holds an unknown `x in Q^c`; by the slack in step 4 we complete
   `Y union {x}` to a consistent world of size exactly `s`, killing `j`.

So no output is safe in every consistent world, and `|Q| < s*L` is insufficient.

Part C runs this construction, with every step asserted, on **every** `Q` of
size `<= s*L - 1` for 15 configurations (up to 2036 query sets per cell). Both
tightness columns confirm the bounds are used, not decorative: `max|Y|` reaches
`s-1` exactly (e.g. `m=7,s=6,L=1`: `|Y|=5=s-1`), and `|Y|+|Q^c|-(s+1)` hits
`0` in 10 of 15 rows.

### 4.3 The checks are discriminating (anti-vacuity)

* **Part D** replays the identical certificate at `|Q| = s*L` (the `s` disjoint
  blocks). It **must** break, and does in 13/13 cells: `|Y| = s > s-1` and some
  output IS safe. A certificate that also "passed" at `s*L` would be proving
  nothing.
* **Part E** contains a self-control on the DP: a batch that leaked per-query
  adaptivity would force `D_2 = H` in every cell, so the probe asserts that at
  least one `s = 2, L >= 4` cell has `D_2 > H`. It has 4.
* **Part F** shows the hypothesis `m > s*L` is load bearing, not decorative.
* **Part 0** checks the *filter itself*. Every later part prunes answer patterns
  with `consistent(m,s,q0,q1)`; a wrong filter there could silently delete the
  adversary's true winning transcript and make every lower bound vacuous. Part 0
  compares that closed form against brute-force world enumeration on all 12960
  `(q0,q1)` states for `m in {4,...,7}`, `s in {0,...,3}`. Exact agreement.
* **Mutation test (run manually, not part of the script).** Three mutants were
  built in `/tmp/n3mut/` and all three died with `AssertionError`, exit 1:
  (1) claiming `D_1 = sL-1` -> part B fails in 15 cells; (2) relaxing the hit
  set to `|Y| <= s` (the disproved `s-1`-private style relaxation) and widening
  the sweep to `|Q| <= sL` -> part C fails with "some output is safe in every
  consistent world"; (3) substituting `H` for `D_b`, `b >= 2` -> the part E
  batch control fails.

### 4.4 Independent code paths

Part E2 recomputes `D_1` and `D_2` with `D1_naive` / `D2_naive` -- no dihedral

`scripts/SUPPORT_depth_probe.optimal_depth` on `ball_windows(m, r)`,
`L = 2r-1`. All agree on all 10 cross-checked cells.

## 6. What this does NOT establish

1. **Nothing here is PROVED in the project's sense.** No Lean module was
   written and no compile was run, so there is no `*.compile.receipt.json`.
   N3-1 has a complete elementary pen-and-paper proof (section 4) whose every
   step is machine-checked exhaustively on a finite grid -- that is
   **NUMERICAL EVIDENCE plus an unmechanised proof**, not a receipt.
2. **The prior Support Lean modules do not carry receipts either.** Checked
   today in `work/p13_conjectures/`: `LeanSupportCardinalityQueryLawV1`,
   `LeanSupportAdaptiveQuerySeparationV1` and `LeanSupportMultiTipGeometryV1`
   have a `.compile.log` with clean `#print axioms` lines and an `.olean`, but
   **no `.compile.receipt.json`**; `LeanSupportLineUnionV1` and
   `LeanSupportPrivateWindowV1` have an `.olean` and **neither a receipt nor a
   log**. Only 20 receipts exist in the whole directory and all 20 are D6
   modules. Any downstream document that calls a Support claim "PROVED" by the
   stated standard is overstating it. (Also: `LeanSupportLineUnionV1` and
   `LeanSupportPrivateWindowV1` are absent from the knowledge graph, so
   `gq.py` cannot be used to check their reverse dependencies.)
3. **The parity law for `H` remains a conjecture.** This probe re-verified
   `H = floor(s/2)(L+1) + (s mod 2)L` exactly on 24 cells (including even `L`,
   which the prior sweep never covered), and cross-checked odd-`L` cells against
   the repo routine. It is not proved. Therefore the closed-form statement
   "the adaptivity gain is `< 2` for all `m, s, L`" is **conditional on that
   law**. What is unconditional is: on every cell where `H` was computed
   exactly, the measured gain was `<= 1.778`.
4. **N3-3 is a conjecture generated from a table, nothing more.** The
   `s = 2` round count `floor(L/2)+1` is a fit to seven points (`L = 1..7`).
   The `D_2` values for `s = 2` fit `L + 1 + floor((L-1)/3)` on `L = 1..8`; that
   fit is **NOT asserted** -- eight points do not determine a formula. The
   observation "`s >= 3` reaches `H` in two batches" is verified only for
   `s in {3,4,5}` and `L <= 5`, and there is no reason yet to believe it for
   large `L`.
5. **Deterministic, zero-error, noiseless only.** Nothing is claimed for
   randomised protocols, for distributional / average-case cost, for noisy
   answers (already covered externally by JMLR v25 23-1484), or for
   approximate safety (`eps > 0` with a nontrivial threshold). The general
   heterogeneous window families of `SUPPORT_law_probe.py` part E are NOT
   addressed: N3-1 is stated for homogeneous cyclic windows only.
6. **No claim about non-cyclic window hypergraphs.** `SUPPORT_law_probe.py`
   part H already shows the general law is a kernel-family statement; N3 does
   not extend it, and the `s*L` identity uses cyclicity twice (every point lies
   in exactly `L` windows; windows inside `Q` are line intervals after one cut).
7. **No novelty claim from noise.** Per the package brief, the noisy-outcome
   ODT regime is prior art. The only thing here that could be novel is the
   exact kernel-specific round tradeoff of N3-3, and that is currently a
   fourteen-row table, not a theorem.
8. **`D_b` is the batch model with the batch committed before its replies.**
   It is not the "at most `b` adaptive rounds of unbounded size where a query
   may depend on earlier queries in the same round" model; the DP charges the
   full `|Q|` for a batch even if the answers make some of it redundant.
