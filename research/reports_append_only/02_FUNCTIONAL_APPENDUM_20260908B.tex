\section*{63. The censoring is explained, and it is not an allocation phenomenon}
Addendum A, Section 57, reported that both allocator defects were repaired and \emph{the censoring did not move}, and concluded that certification failure is a property of the instance family. The mechanism is now measured. The \texttt{true\_topk\_gap} field, added to the v3 output on 7 September and never analysed, predicts certification almost by itself. Over all $360$ runs ($6$ variants $\times$ $60$):

Point-biserial $r=+0.6826$, $p=1.07\times10^{-50}$. Median gap $0.4771$ when a certificate is emitted against $0.1447$ when censored, a ratio of $3.30$. The ratio is $3.3$--$3.9$ for \emph{every} variant including the oracle $C_{\text{known }\sigma}$, i.e.\ the allocation policy barely matters beside the gap. An independent run at larger $n$ found $75/75$ instances with gap below $0.1$ uncertified and $78/79$ certified at gap $\ge0.4$.

\claimbox{\textbf{Confound.} The chain's headline --- ``query/functional geometry controls certification complexity'' --- is not established by these runs. What the experiment varies is the instance family's top-$k$ gap distribution, and certification cost is the \emph{classical} $1/\Delta^2$ law of best-arm identification. \eclass{DEMOTED: headline confounded; the measurement stands, the attribution does not}}

\textbf{What is not claimed.} This does not show certification is impossible below the gap threshold. The runner uses a finite-horizon Bonferroni bound that is deliberately conservative, so the observed threshold is an artefact of the bound as much as of the family. Separating the two requires a gap-stratified comparison at fixed gap, which has not been run.

\section*{64. The experiment this demands}
Compare policies \emph{within} a gap stratum. At $20$ instances per seed each stratum holds $12$ runs per variant, too few to separate anything; the comparison needs enough instances that each quintile carries tens of runs per variant. If the six policies remain indistinguishable inside a stratum, the chain has no allocation result --- and that is a conclusion, not a failure.
