\section*{79. NARROWING: the transfer matrix is not yet a deficiency}
Addendum B, Section 77, stated:
\begin{center}\scriptsize\oldclaim{the quantity the transfer matrix reports is a deficiency, measured in one simulator under one budget}\end{center}
That goes too far. Relabelling a regret matrix as a Le Cam deficiency does not create the equivalence. A deficiency statement is relative to a specified class of loss functions and a specified optimisation over transition kernels; the current matrix reports regret of a chosen decision rule on a fixed panel, against a fixed reference, at a fixed budget.

\claimbox{\textbf{What is required before the word is used.} An explicit correspondence between (i) the method--query cell's reported regret and (ii) the optimal value of the transition-kernel problem defining deficiency, over the loss class the chain actually cares about. Until that is proved, the report should say ``transfer regret under a matched budget'' and cite deficiency only as the adjacent framework.}
