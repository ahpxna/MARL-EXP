\section*{69. CORRECTION to the census of Section 67}
Section 67, written earlier today, reported \textbf{9} \texttt{native\_decide} uses across three modules. That number is wrong. Re-counting by taking every occurrence of the bare identifier and classifying it by reading its surrounding context:

Each of the three modules exists in two copies (\texttt{work/p12} and \texttt{work/p13\_conjectures}) with identical content, so $16$ counts distinct source positions once.

\textbf{Why it was wrong, and the irony.} Section 67 closed with a method note saying that searching for \texttt{by native\_decide} misses the tactic when it sits on the following line, and that the reliable procedure is to count occurrences and classify each. The count published in that same section was produced by the very pattern it warns against: it caught the five \texttt{opt*\_abs} one-liners of the $\chi\ge5$ witness and missed \texttt{unique\_abs1}--\texttt{unique\_abs5} immediately below them, whose \texttt{native\_decide} is on the line after \texttt{by}. It also missed two of the four uses in the $\chi=4$ witness for the same reason.
\claimbox{\textbf{Writing a rule down does not apply it.} The corrected procedure was stated and then not executed in the same section. Recorded here in full rather than silently patched, because the failure is about method, and the ledger's value depends on method failures being visible.}

\section*{70. What the corrected number changes, and what it does not}
\begin{itemize}
\item \textbf{Unchanged:} the module set is the same three; the audited $59$ names still contain \textbf{zero} \texttt{ofReduceBool}; the evidence class of the $\chi\ge5$ witness is still \eclass{COMPILED ARTIFACT resting on \texttt{native\_decide}}.
\item \textbf{Changed:} the promotion is twice the work it looked like. The five \texttt{unique\_abs} statements are not closed evaluations but quantifications over all $128$ subsets of a $7$-element set, each requiring a signed seven-term integer sum and one \texttt{natAbs}.
\item \textbf{Still cheap in absolute terms:} $128\times7=896$ kernel integer additions for the whole uniqueness block. That is a bounded computation, not a case explosion, so kernel \texttt{decide} remains the right instrument and \textbf{no brute-force search is involved}.
\end{itemize}

\section*{71. The promotion, implemented}
A new module \texttt{Lean\allowbreak Structural\allowbreak Scalar\allowbreak Chi5\allowbreak KernelV1} re-proves all ten statements about the \emph{same} definitions --- it imports the original rather than copying it, so the promotion applies to the witness actually in use --- with kernel \texttt{decide} in place of \texttt{native\_decide}. Each statement is a separate theorem so a failure localises. The original module is untouched. A companion \texttt{Axiom\allowbreak Audit\allowbreak Structural\allowbreak Scalar\allowbreak Chi5\allowbreak KernelV1} prints the axiom set of all ten.
