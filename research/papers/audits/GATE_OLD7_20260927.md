## Known artefact, not a module failure: `import Aesop`

At freeze time the gate printed `IMPORT OUTSIDE GATE: LeanD6AllocationFiniteBridgeV1 imports Aesop`.
`verify_all.sh` accepts only `Mathlib*` imports as external. It counts Aesop, a package that
ships with Mathlib, as a missing local import and sets `imports_closed=0`. So the final
SUMMARY line will read **SMOKE FAIL even if every module compiles cleanly**.

- The build is unaffected: `make` only orders local imports, and `lean` resolves Aesop from
  the packages directory.
- This is the only module in the 251-module closure that imports a non-Mathlib package directly.
- When reading the final verdict, separate it: if the only non-OK item is `imports_closed=0`
  with that single line, the corpus result is a pass up to this script classification.
- Fix belongs to the coordinator (script or module): either allow `Aesop` in the import
  check, or change that module to `import Mathlib.Tactic` or similar.
